# 生图错误提示与恢复

失败时读取本表。先说发生了什么，再说明已确认的状态，最后给一个可执行的下一步。默认仅展示相关的一两句；脚本的“技术详情”用于排查，按需展开，不直接倾倒英文响应、堆栈或日志，不复述密钥。

## 固定文案

| 场景 / 证据 | 面向用户的提示 | 下一步与处理 |
|---|---|---|
| 尚无配置 | 还没有连接生图服务。完成配置后，就可以开始创作。 | 打开固定初始化表单 |
| 配置被删除或停用 | 当前配置暂不可用，请选择其他配置，或重新连接服务。 | 选择启用的配置，或初始化 |
| 配置损坏 | 暂时无法读取生图配置。已有文件已保留，可以修复配置或重新连接服务。 | 报出文件位置；不覆盖原文件 |
| Keychain 被锁、授权取消 | 暂时无法读取 API Key。请解锁钥匙串，并在系统提示中允许访问后重试。 | 停止反复弹窗；等待用户解锁 |
| 本机无 Key | 这台设备还没有保存此服务的 API Key，请重新连接一次。 | 编辑连接 |
| 厂家尚无主模型 | 还没有为 {厂家} 设置主模型，选好一个就能开始。 | 打开模型配置表单并定位该组 |
| 简称歧义 | “{简称}”对应多个模型，请选择这次要使用的一个。 | 仅列当前站点真实候选 ID |
| 模型不在列表中 | 当前服务的模型列表中没有找到 {模型}。可以刷新列表，或选择其他模型。 | 刷新或打开模型配置；保留原配置 |
| 主模型明确不可用且已配备选 | {主模型} 暂不可用，正在尝试你设置的备选 {备选模型}。 | 最多尝试同厂家一个备选 |
| 主备均被拒绝 | 当前主备模型都未能完成生成，请更换模型后再试。 | 打开模型配置；具体失败原因优先说明 |
| 模型不可用且无备选 | 当前模型暂不可用，且没有设置备选，请更换模型后再试。 | 打开模型配置；显式单次模型仅提示更换模型 |
| 原生协议不兼容 | 这个模型与当前请求协议不匹配，请调整连接协议或选择兼容的模型。 | 提交前停止；不擅自切协议 |
| 本地参数校验失败 | 当前模型不支持这组图片参数：{简短原因}。请调整后再生成。此次未提交生成请求。 | 沿用原意图调整；不静默降画质 |
| 参考图片无法读取 | 暂时无法读取这张参考图，请重新选择图片，或转换为支持的格式。此次未提交生成请求。 | 重新选择本地图片或支持的格式 |
| 参考图传输方式或数量不支持 | 当前连接无法按这种方式使用参考图：{简短原因}。请调整后继续。此次未提交生成请求。 | 修正字段、传输或数量；不丢弃参考图 |
| 提交前输出目录不可写 | 图片保存位置暂时不可用，请选择可写目录或释放空间后继续。此次未提交生成请求。 | 指定可写目录 |
| 401 / 密钥无效 | 服务未通过密钥验证，请检查 API Key 是否有效，或更新密钥后重试。 | 编辑连接；同一个 Key 不轮换模型 |
| 402 / insufficient_quota 等余额错误 | 服务提示余额或额度不足，请到服务站点核对账户状态后再试。 | 停止重试与自动备选，不把余额不足当限流 |
| 普通 403 | 当前账户没有完成这次请求的权限，请到服务站点检查账户状态和访问权限。 | 停止；明确模型权限拒绝才可使用已设置备选 |
| 内容拒绝 | 服务未接受这次创作内容。你可以调整描述后再试。 | 不自动换模型绕过；只在服务明确指出内容问题时使用此文案 |
| 真正的 429 限流 | 当前请求较多，服务建议等待 {时间} 后再试。 | 尊重 Retry-After；无该字段则说“请稍后再试”，不编等待时间；等待超过 60 秒停止 |
| DNS / 拒绝连接 | 暂时连接不上生图服务，请检查网络和服务地址后重试。 | 仅明确未送达时有限重试 |
| TLS / 证书错误 | 与生图服务的安全连接未能建立，请稍后重试；若持续出现，请检查网络或联系服务方。 | 不关闭证书校验 |
| 提交后超时、连接中断 | 连接中断，暂时无法确认这次是否已生成或计费。已暂停重复提交，请先核对服务记录。 | 有任务或图片才恢复，否则先查服务记录 |
| 408 / 5xx | 生图服务暂时异常，未收到可用图片。这次的处理和计费结果尚未确认，已暂停重复提交。 | 不重新生成、不切备选 |
| 响应格式异常 | 服务返回了异常结果，暂时无法取得图片。已保留本次记录，请核对服务端任务状态。 | 不将解析失败当作未生成 |
| 查询暂时失败且还会重试 | 任务已提交，暂时无法获取最新进度。正在重新查询，不会重复生成。 | 仅 GET 重试，尊重等待提示；重试用尽后改说“已暂停本地查询” |
| 本地轮询时限 | 这次生成等待较久，已暂停本地查询。任务可能仍在运行，可以稍后继续查询。 | 恢复查询，不承诺远端已取消 |
| 服务返回 failed / canceled | 服务返回这次任务未完成：{明确原因}。请处理后再试。 | 如实区分服务失败或取消；无退款证据不承诺退款 |
| completed 但无图片 | 服务显示任务已完成，但没有返回可用图片。请先核对服务端结果。 | 不声称成功，不自动补生成 |
| 已有图片引用但下载失败 | 已收到图片结果，但暂时无法保存到本地。可以继续下载，无需重新生成。 | 恢复原图片下载 |
| 图片链接明确已过期 | 图片链接已失效，请尝试获取原任务的新链接。 | 有任务编号可重新查询；无编号去服务记录；单凭 403/404 不断言过期 |
| 无效 base64 / 非图片响应 | 服务返回的内容不是有效图片，暂时无法展示。已保留本次记录，供检查原任务结果。 | 不展示错误页；不重新提交生成 |
| 收到图片后保存失败 | 已收到图片结果，但保存失败。请更换保存位置或释放空间，再继续保存。 | resume 配合 --out-dir / --output；保留已存图片 |
| 少于请求张数 | 已完成 {已保存}/{请求} 张，图片已保存；其余图片尚未返回。 | 展示现有图片；不自动补生成 |
| 尝试次数达到上限 | 本次已达到生成尝试上限，已停止继续提交。可以查看已尝试的模型和结果，再决定是否继续。 | 不自动增加上限 |
| 无任务 ID 且无图片 | 本次没有可查询的任务编号或图片结果，请先核对服务记录，再决定是否重新生成。 | 不展示无法执行的 resume 入口 |
| 恢复文件缺失、损坏、原连接变化 | 暂时无法恢复这次任务：{具体原因}。请找回原任务记录或恢复原服务连接后继续。 | 报出具体缺项，不覆盖原记录，不将旧 Key 发到新地址 |
| 未识别错误 | 这次未能取得图片，原因暂未识别。可以查看详情后继续排查。 | 说明现有证据与可用恢复动作，不猜原因 |

## 状态决定动作

- 只有本地提交前校验失败才能说“此次未提交生成请求”。不能用非零退出码推断是否到达服务端。
- 有任务编号且不是已知失败或空结果终态：提供 `generate.js --resume <记录>`，继续查询原任务。
- 有图片结果：提供同一恢复命令继续保存，允许换输出位置；保留已存图片。收到图片不能据此断言已扣款。
- 两者都没有：记录仅供诊断，先核对服务站点记录。“重试”若意味着再次生图，须说明这一点，遵守用户已有授权和宿主费用规则。
- 默认停止跨站点；用户明确开启跨站点备选时也不能穿透余额不足、内容拒绝、参数错误或未知结果。
- 首句优先反映最后一次真实失败。例如备选遇到余额不足，应提示余额问题，不能被“主备失败”泛化文案遮住。
